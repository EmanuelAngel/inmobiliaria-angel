El objetivo de esta entrega previa es definir la temática, el alcance funcional y el modelo de datos inicial del Proyecto Integrador Final. Esta instancia permitirá validar que la propuesta cumpla con la complejidad técnica requerida antes de comenzar la etapa intensiva de desarrollo.

La entrega se realizará mediante un archivo PDF o enlace al repositorio de GitHub y debe contener estrictamente los siguientes puntos:

1. Narrativa del Proyecto y Descripción del Problema

Escribir una breve presentación del sistema propuesto que detalle:

- Datos del Grupo: Integrantes (Apellido, Nombre y Email de cada uno).
- Título / Nombre del Proyecto y Temática elegida (ej. Taller Mecánico, Clínica Médica, Sistema Educativo, etc.).
- Descripción de la Problemática: ¿Qué problema real o de negocio busca resolver la aplicación?
- Propuesta de Solución: Explicación general de las funcionalidades que ofrecerá el sistema web MVC para resolver dicha problemática.

2. Modelo de Datos y Diagrama Entidad-Relación (DER)

Presentar el diseño preliminar de la base de datos que sostendrá el sistema:

- Diagrama Entidad-Relación (DER) o Diagrama de Clases: Adjuntar la imagen clara y legible del esquema de base de datos.
- Listado y Descripción de Entidades: Identificar y describir brevemente las entidades/tablas.
- Descripción de Relaciones: Explicar brevemente el sentido o propósito de las relaciones no triviales.
