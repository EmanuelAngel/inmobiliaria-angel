Desarrollar un sitio web utilizando ASP.Net MVC para una inmobiliaria teniendo en cuenta la [narrativa](../narrativa.md).

Para la primera entrega, realizar ABM de Propietarios e Inquilinos.

Criterios de Entrega del Repositorio:

El repositorio del proyecto debe incluir obligatoriamente:

- Archivo .gitignore en la raíz, acorde a las tecnologías del proyecto (evitando subir binarios y dependencias).
- Script .sql con las sentencias necesarias para crear e inicializar la base de datos.
- Archivo README.md que incluya:
    - Lista completa de integrantes del grupo.
    - Diagrama Entidad-Relación (DER) o Diagrama de Clases.
    - Instrucciones claras para levantar la base de datos a partir del archivo `.sql`.
